¿Qué es esta herramienta?

El Validador analiza bases de licitación, extrae requisitos, los compara contra tu propuesta y genera formatos. Usa inteligencia artificial para reducir errores de cumplimiento.

Flujo de trabajo

1Extraer Requisitos — Sube el PDF de las bases o pega el texto. El sistema identifica todos los requisitos automáticamente.
2Contrapunteo — Sube tus documentos de propuesta. El sistema compara lo que tienes vs. lo que piden y detecta faltantes.
3Generar Formatos — Selecciona la razón social y genera cartas, manifestaciones y formatos con datos pre-llenados.
4Validación Final — Sube la propuesta completa armada. Revisión requisito por requisito para dar veredicto PASA / NO PASA.

Tips importantes

• PDFs grandes: El sistema los procesa automáticamente. Si tarda, es normal — está leyendo página por página.
• Guardar sesión: Usa el botón 💾 para guardar tu avance. Puedes cerrar y retomar otro día desde el Paso 3 o 4.
• Banco de reglas: Cada vez que detectes algo importante (ej: "en BC siempre piden SIBSO"), captúralo como regla. Se aplicará en TODAS las futuras validaciones.
• Razones sociales: Registra los datos de cada empresa una sola vez. Quedan guardados permanentemente.
• Formatos generados: Son editables. Revisa siempre antes de usar — la IA genera el 95% pero el 5% depende de tu revisión.

Archivos soportados

PDF, Word (.docx), imágenes (PNG, JPG), texto plano (.txt). Para mejores resultados con PDFs escaneados, usa PDFs con texto seleccionable.
